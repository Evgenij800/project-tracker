# Брендбук корпоративной системы управления проектами (Apex Tracker)

## 1. Фирменные цвета (Color Palette)

Единая цветовая палитра задает современный, строгий и надежный корпоративный стиль для IT и проектного менеджмента:

- **Основной цвет (Primary):** Глубокий сине-серый (Corporate Navy) — `#0f172a` (используется для шапки, основных заголовков и навигации).
- **Акцентный цвет (Accent):** Яркий технологичный синий (Electric Blue / Teal) — `#0284c7` (используется для кнопок действия, ссылок, активных элементов и акцентов).
- **Фоновый цвет (Background):** Чистый светло-серый (Off-White / Slate Light) — `#f8fafc` (используется как фон страниц).
- **Цвет карточек и контейнеров (Surface):** Чистый белый — `#ffffff` с мягкими тенями.
- **Статусные цвета:**
  - Успешно / Завершено: `#10b981` (Emerald)
  - В процессе / Внимание: `#f59e0b` (Amber)
  - Высокий приоритет / Ошибка: `#ef4444` (Rose)

---

## 2. Типографика (Typography)

Для обеспечения идеальной читаемости на всех экранах и устройствах используется современный системный стек шрифтов:

- **Шрифт для заголовков (Headings):** `'Segoe UI', Inter, system-ui, -apple-system, sans-serif` (Начертание: Bold / Semibold, строгие пропорции).
- **Шрифт для основного текста (Body):** `'Segoe UI', system-ui, -apple-system, sans-serif` (Начертание: Regular / Medium, высокая разборчивость).

---

## 3. Правила использования логотипа (Logo Guidelines)

- **Концепция:** Логотип состоит из геометрического знака взаимосвязанных узлов (символизирующих интеграцию модулей проектов, оплат и кадров) и текстовой части названия системы.
- **Формат:** Векторный SVG для обеспечения идеальной четкости на Retina-дисплеях.
- **Размещение:**
  - В шапке приложения (Navbar): слева от названия системы, размер 32x32px.
  - На странице авторизации: по центру над формой входа, размер 64x64px.
- **Охранное поле (Clear Space):** Вокруг логотипа должен сохраняться отступ, равный минимум половине высоты знака. Запрещено искажать пропорции или изменять фирменные цвета логотипа.
